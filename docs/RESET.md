# 🧹 حذف كل البيانات والبداية من أول وجديد

زر واحد جوه التطبيق بيمسح **كل بيانات الطلاب والأكواد والسجلات**، وبعد المسح
التطبيق يرجع **نضيف تماماً** — وأنت تفضل مسجّل دخول بنفس إيميلك،
ومحدش تاني يقدر يدخل (مفيش أي صفحة تسجيل/إنشاء إدارة في التطبيق أصلاً).

---

## الطريقة 1: من داخل التطبيق (المُفضّلة)

1. سجّل دخول **سوبر أدمن**.
2. من القائمة → تبويب **«حذف الطلاب»**.
3. في الأول هتلاقي بلوك أحمر **«حذف كل البيانات»** → اضغط الزرار.
4. اكتب كلمة `DELETE` → **«احذف كل حاجة نهائياً»**.

### إيه اللي بيتمسح؟
| المجموعة / المكان | المحتوى |
| --- | --- |
| `students` | كل الطلاب وملفاتهم وجداولهم |
| `activationCodes` | كل أكواد التفعيل |
| `auditLogs` | **سجلات التدقيق بالكامل** (حذف فعلي — مش أرشفة) |
| `bookFiles` (+ `chunks`) | بقايا قديمة من زمن رفع الملفات |
| `staff` | كل الأدوار **غير دورك** (أي حد كان أدمن/إدمن بيشال) |
| `localStorage` | كل مفاتيح `ssp_*` |

**بيفضل موجود (مقصود):**
| المكان | السبب |
| --- | --- |
| `staff/{uid}` بتاعك | إنت الإدارة العليا — التطبيق مقفول على حسابك |
| Firebase Auth بتاعك | تفضل قادر تسجّل دخول بنفس الإيميل/كلمة السر |
| `appMeta/bootstrap` | مفيش أي «نافذة إنشاء أدمن» بتتفتح تاني |

بعد التنفيذ:
- البيانات كلها بتروح فوراً — والتطبيق بيفضل على جلستك مع لوحة نظيفة.
- **مفيش** `requires-recent-login` في الحذف ده (بنمّسح بيانات مش حسابات).

> ⚠️ لو ظهرت `permission-denied`، معناها إن قواعد Firestore مش منشورة — انشر `firestore.rules` الأول.

---

## الطريقة 2: من Firebase Console (لو مش قادر تدخل التطبيق)

1. **Firestore Database**: امسح كل collection:
   `students` • `staff` • `auditLogs` • `activationCodes` • `bookFiles` • `appMeta`
   (كل واحدة → ⋮ → *Delete collection*)
2. **Rules**: انشر `firestore.rules` من الريبو.
   (Storage مش مستخدم — `storage.rules` بيقفل كل المسارات، مفيش حاجة تمسحها هناك.)
3. **Authentication → Users**: لو حذفت المستخدمين كمان، أنشئ حساب **جديد** لحسابك
   (Authentication → Add user → Email/Password). ملاحظة: التطبيق **مش فيه أي صفحة
   إنشاء إدارة** — الحساب بيتعمل من الـ Console بس، مرة واحدة.

---

## بعد الحذف — أول 3 خطوات

1. سجّل دخول **بس بحسابك** (إيميل + كلمة السر) — مفيش إنشاء حساب جوه التطبيق أصلاً.
2. اعمل **كود تفعيل** من تاب «أكواد التفعيل».
3. سجّل طالب جديد بالكود من «بوابة الطلاب» → أول ما يدخل يختار سنته، والتطبيق يوزّع
   منهج السنة على أيامه ويطلعله الجدول الكامل.
